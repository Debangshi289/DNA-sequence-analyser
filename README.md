# DNA Sequence Analyzer 🧬

# Overview

The DNA Sequence Analyzer is a beginner-level bioinformatics project
developed in Python to perform basic analysis of DNA sequences.

The program accepts a DNA sequence as input, validates the sequence,
and performs several fundamental sequence analysis tasks.

# Features

-DNA sequence validation
- Nucleotide counting (A, T, G, C)
- DNA sequence length calculation
- GC content calculation
- AT content calculation
- Complementary DNA sequence generation
- Reverse complement generation
- DNA to RNA transcription
 Invalid nucleotide detection

# Biological Concepts

This project applies fundamental concepts of molecular biology and
bioinformatics, including:

- DNA nucleotides
- Complementary base pairing
- GC and AT composition
- DNA sequence orientation
- Reverse complements
- Transcription from DNA to RNA

# Technologies Used

- Python 3
- Visual Studio Code
